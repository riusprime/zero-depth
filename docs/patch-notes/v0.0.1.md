# {{TITLE}} v0.0.1 — Ground Plane
_2026-10-06_ · The foundations: a cube you can move, aim and dash on a stage, on keyboard+mouse or gamepad.

## New Features
### A stage to stand on
The game boots to a menu and opens a single test stage seen through a fixed isometric camera. You play a cube:
move, aim and dash. There are no enemies to fight yet; the targets on the stage only stand and shoot so the
camera, the outlines and the see-through-walls view can be judged.
- Keyboard+mouse and gamepad from day one: the same moves on both, with aim by mouse or by the right stick.
- Your key and button bindings are kept in your profile.

### Two languages
Every menu and label is in English and Spanish, in a font chosen for legibility (Atkinson Hyperlegible).

## User Interface
- Main menu: Play, Options, Credits and Quit. The version is shown in the corner.
- Pause menu during play.
- Options: language, volumes, VSync and a frame-rate cap.
- Credits: the engine's and the font's licences.
