# Art request: textures to replace the code-made looks (v0.8.0, owner 2026-10-15)

Owner, 2026-10-15: "This checklist does not include any 2d textures for some modeling that you have done and I think
itd be better looking if we created real textures like with the player animations so, also include in that document
the textures replacement and prompts for them".

v0.8.0 drew many new effects with **code-made noise** (procedural shaders) because the free texture sites were blocked
from the build machine: the boss orbs, beams, ground cracks, lava, marker fills, the menus' stone. The player's attacks
look better because they use **your painted atlases** (`assets/textures/vfx/fx_*.png`). This list gives each code-made
look a texture of yours, in the same style. Each row names what it replaces, so the lead can swap it in.

Supersedes [`v0.8.0_ART_LIST.md`](v0.8.0_ART_LIST.md) §5 (its four rows are folded in below).

## Two kinds of texture

**A. Effects (VFX):** the same rules as [`../VFX_REQUESTS.md`](../VFX_REQUESTS.md):
- pure black background (#000000), because brightness becomes transparency;
- square PNG, 1024 unless the row says 512;
- "2×2" means four separate variants, one centred in each quarter, nothing crossing the middle lines;
  "1×4" means four horizontal strips stacked, one per row;
- chunky, cel-shaded, 2–3 flat tone bands; no text, frame or ground.

**VFX prefix** (paste before each A prompt):
> stylized game VFX texture, chunky low-poly game art style, cel shaded with 2-3 flat tone bands, crisp simple
> shapes, no photo realism, centered, isolated on a pure black background, no text, no frame, no ground,

**B. Surfaces:** real colour textures that tile seamlessly (floors, stone, lava crust, menu slabs):
- square PNG 1024, **seamless on all four edges**;
- seen straight from above (or straight on for the menu slab), flat even light, no shadows baked in;
- the same chunky hand-painted low-poly look as your kit's textures.

**Surface prefix** (paste before each B prompt):
> seamless tileable game texture, stylized hand-painted low-poly game art, chunky flat-shaded shapes, flat even
> lighting, no shadows, no perspective, no text, no logo, edges tile perfectly,

Name each file by its id and drop it in `unprocessed_images/vfx/` (A) or `unprocessed_images/kit/` (B).

## How they go in
The lead crops each sheet, turns brightness into transparency for the VFX, lists every file with its hash in
`assets/models/manifest.json`, rebuilds the credits and swaps the code look for yours, keeping the code look as the
fallback. Effects keep their colours from the game where the code tints them, so a grey or white texture is fine for
anything marked "tinted" in the evidence; when in doubt, paint it in the colours the prompt names.
