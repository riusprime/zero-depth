# Art request: 14 enemies, 11 props and one effect texture (owner, 2026-11-20)

Owner, 2026-11-20: "Can you add the full detailed prompts as we worked on the latests oners so I just copy paste them,
add the prefix if they have one to the prompt already and give them as much detail as possible so there is consistency
between assets". Every prompt below is complete: paste it as it is. There is no prefix to add and no colour to fill in.

## How to use this

1. **Image step:** paste the **Image prompt** into your image tool. If the tool takes a reference image, attach
   `docs/art/enemies_visual_reference.png` for the enemies (your Charger, Warden and Needle). For the props, attach any
   render of your kit, for example `docs/art/look_reference.webp`.
2. **3D step:** give the image you picked to your 3D tool, with the **3D prompt**.
3. **Negative prompt:** if either tool has one, use the shared one for that group.
4. **Send** the `.glb` files under the names below. Several pieces in one file is fine: the lead cuts them out, as it
   did with the room packs. The lead installs each model, cuts its moving parts, animates it in code and puts the
   enemies on VAT. A rig is never needed.

**What the last delivery taught (2026-11-19).** Your 3D tool keeps a model as one closed mesh, so "separate parts"
only helps when the part stands clear of the body. It also drops small held objects and changes colours: the Wire
Weaver came without its posts, the Glacier Turtle without any bronze, and the Gravity Node violet instead of yellow.
So each prompt below repeats its role colour in both steps, and each ends with a **Check before you send** line. If
the 3D model fails that check, regenerate it before sending.

> text, letters, numbers, logo, watermark, background scenery, ground, floor, base, pedestal, stand, baked shadows,

## What every enemy shares (the Charger's family)

- **Head:** a faceted, ridged shell or hood in the role colour on top. Under it, a dark charcoal shield-shaped face
  plate with **one** glowing gem visor in the role colour. Never two eyes, never a mouth with teeth.
- **Body:** charcoal steel, worn and scratched (about `#3A3A3E` to `#6A6462`).
- **Limbs:** grey segmented limbs with bone-coloured tips (about `#D9CDB8`).
- **Greys stay neutral.** Every biome tints them, and a warm or blue grey fights the tint.
- **Glow** only on the visor and the one feature a prompt names. Everything else is matte.
- **Read from above:** the camera looks down about 35° from far away, so an enemy is 60–120 px tall on screen. A clear
  silhouette beats detail. If two of these would look alike as black shapes, one of them is wrong.
- **Proportions:** chunky, thick plates, few big facets. About 5k triangles for a regular enemy and 1.5k for a horde
  critter.

**Sizes.** The footprint is the enemy's collision circle in the game. The height is a target next to the hero, who
stands about 1.7 m. The game scales the model to the footprint, so the proportions matter more than the metres.
