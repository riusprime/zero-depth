# v0.9.0: every new asset the owner can make (the full list, 2026-10-22)

Owner, 2026-10-22: "i'd need the document with all the new assets needed". This is everything v0.9.0's PLAN
([`../../roadmap/v0.9.0/PLAN.md`](../../roadmap/v0.9.0/PLAN.md)) asks for, ordered by the wave that needs it.
**Nothing waits on art:** every item gets a code-made stand-in in the step that needs it, and your file replaces it
when it arrives (L15). Tick what you deliver.

**Delivery:** drop the `.glb` files (with their textures), PNGs and WAVs into `unprocessed_images/` (sounds into
`unprocessed_images/audio_v090/`), named by the id, and say so in chat. The lead prepares and installs them
(`scripts/assets/mi_prep.py`: sized, simplified to the triangle budget, maps 1024), lists them in the manifests and
runs the asset tests.

**Shared rules (all models):** the look of your kit and [`../look_reference.webp`](../look_reference.webp): chunky,
chipped, weathered low-poly; worn metal, concrete and stone; no baked lighting or shadows; no text, letters or logos;
one object, no ground plane; readable from an isometric camera about 35° down. **Neutral stone, no glow:** the game
adds every glow and recolours runes per biome or per state. Rigged is a bonus, never needed (the lead animates parts
in code).

**Prefixes:** use the **kit prefix** (props, devices, room pieces) and the **character prefix** and **3D step**
(elites, bosses) from [`../../OWNER_TODO.md`](../../OWNER_TODO.md) §3, then the line in the table. **Negative prompt**
(if the tool has one), for props: *text, letters, logo, watermark, glow, light beams, background scenery, ground
plane, people, baked shadows, realistic photo, many tiny details*.

**Status column:** **ready** = the design is decided, the prompt below is final; **after G1** = the design is decided
in a gate list first (the lead writes the prompts then, in this file).

## 7c. VX textures (the VFX pass, optional: every id has a code fallback)
VX (owner: "every VFX has a high quality layered effect … if you can't generate you can ask for the needed textures")
draws every hero effect in layers from the sheets already installed (flames, embers, lightning, frost burst, splashes,
bubbles, smoke, sparks) plus two sheets made in code. These PNGs make four of the layers crisper. Each id is listed in
`assets/textures/vfx/manifest.json` with its fallback, and the game uses it as soon as the file is installed, with no
code change. **Shared rules:** PNG with transparency, **white or light-grey shading only** (the game tints each element),
no background, no text, no glow halo baked around the edge (the game adds its own), each cell centred with a margin.
A 2 × 2 sheet = four variations in a square grid.
